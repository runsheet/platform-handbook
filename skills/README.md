# skills

The platform's skills: runsheet serves each `skills/<name>/SKILL.md` here to
every org's projects through `skills_list` and `skill_get`, layer
`platform`. A tenant's handbook or a project's own skill of the same name
wins over the one here.

- `prove-it-bites`: show a change's test fails without the change.
- `names-must-resolve`: every name a config file points at exists.
- `match-the-other-side`: take a request's shape from the other service.
- `change-a-shared-number`: measure before and after changing a shared number.
- `cover-every-variant`: test every kind a behaviour is keyed by.
- `walk-the-deploy`: walk each deploy step's tools, hosts and credentials.
- `write-goal`: write a Mesh goal with numbered promises and checks.

See CONTRIBUTING.md to add one.
