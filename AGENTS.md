# Working in the platform handbook

- This repo is read by every tenant. Write nothing tenant-specific or
  runsheet-internal here; that belongs in a tenant or project handbook.
- One skill per `skills/<name>/SKILL.md`. Frontmatter must carry `name` and
  a `description` that says when to use it. Keep steps concrete: commands,
  files to copy, what to check.
- Changes arrive as pull requests; a person merges them.
